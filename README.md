# Odin Recipes
This repo contains files created while following the [Odin Project](https://www.theodinproject.com/) course, "[Fundamentals](https://www.theodinproject.com/paths/foundations/courses/foundations)".

The project consists of creating a website for recipes. This is the first stage of this project, where only HTML markup will be created. CSS will be added at a later point.

The goal is to display an understanding of how HTML works.
